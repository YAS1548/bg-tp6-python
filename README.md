# 🐍 TP6 – Python : bases du langage Python

## 🎯 Objectif du TP

L'objectif de ce TP est de vous familiariser avec les **bases du langage Python**.  
Vous allez mettre en pratique ces notions à travers **2 exercices progressifs**.

---

## 📘 Ressources fournies

- Le fichier **`TP6_Python.pdf`** vous guidera **étape par étape** dans la réalisation du TP.
- Tous les **scripts Python** doivent être écrits dans un fichier nommé **`app.py`**.
- Les **noms de variables** doivent correspondre **minutieusement** à ceux donnés dans chaque exercice.
- Les **fonctions** doivent retourner des **objets JSON**, comme expliqué dans chaque exercice.
- Votre code doit impérativement être **commenté**, en mentionnant pour chaque concept utilisé le **numéro de la diapositive correspondante** du cours.

> Exemple :  
> `# Ici on utilise une boucle (vu dans le slide 45)`

🛑 **Un code sans commentaire est automatiquement rejeté.**

---

## 🧭 Déroulement du TP

1. **Accès à l'énoncé**
   - L'énoncé complet du TP est déposé sur **GitHub**.
   - Le lien de l'assignement est communiqué sur **Google Classroom**.

2. **Création de votre espace de travail**
   - Acceptez l'assignement sur GitHub Classroom.
   - Clonez ensuite votre dépôt individuel.

3. **Réalisation**
   - Complétez le fichier **`app.py`** dans **chaque dossier d'exercice**.
   - Suivez les consignes décrites dans **`TP6_Python.pdf`**.

4. **Soumission**
   - Une fois le travail terminé :
     ```bash
     git add .
     git commit -m "TP6 Python terminé"
     git push origin main
     ```
